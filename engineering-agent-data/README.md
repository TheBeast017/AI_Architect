# engineering-agent-data
Layout from concept doc 17.5. `raw/` = untouched downloads; `licenses/` = license + citation notes per source;
`cad/` = generated/converted STEP/STL; `simulations/` = solver in/out + logs; `processed/` = cleaned metrics;
`manifests/` = design_id -> file index; `splits/` = train/val/test IDs (split by design family, not random rows);
`reports/` = comparison reports. Record units and provenance here for every source added.
